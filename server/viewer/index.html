Traversal event schema — v0.1

This viewer folds a recorded or live event log into view state. The renderer is identical either way — that's the point of the log-based design: live view and recorded replay are one code path.

Transport

Each event is one JSON object. Live: GET /sessions/:file/live (SSE). Recorded: GET /sessions/:file/events (newline-delimited JSON). Timestamps (t) are ms offsets from session start.

Event types

{ t, type: "session_start", session, graph_version }

{ t, type: "user_message",   text }

{ t, type: "search",         query, matches: [coordinate...] }
  // emitted by the search endpoint/tool handler

{ t, type: "node_fetch",     coordinate, revisit: bool }
  // emitted whenever a node page / node JSON is retrieved

{ t, type: "edge_follow",    from, to, edge_type }
  // edge_type ∈ flow | escalation | premise |
  //             resolution | retreat | redirect
  // emitted when a connection listed on a fetched node
  // is followed to another fetch within the same turn

{ t, type: "unmapped",       query, kind, nearest: [coordinate...] }
  // search returned no direct match. kind classifies the
  // suspected gap:
  //   "alias" — premise is covered, phrasing didn't route
  //             (patch = new aliases on existing nodes)
  //   "edge"  — both nodes exist, the move between them
  //             isn't typed (patch = new connection)
  //   "node"  — no node covers the structural pattern
  //             (patch = new argument, rare by hypothesis)
  // RENDERED PROMINENTLY, NOT HIDDEN — the patch queue is
  // the hardening loop made visible.

{ t, type: "assistant_message", text, sources: [coordinate...] }

{ t, type: "session_end",    stats }

Design notes

1. State lives in the log. The client folds events into view state (visited set, trail, patch count). Refresh-safe, and every session is a recorded demo for free.

2. No model cooperation required. The model never narrates its path; instrumented tools are the path. A model that skips the graph produces an honest, empty trail — also informative.

3. Misses are first-class, and typed. Nodes map patterns, not instances — so most unmapped events are routing gaps (alias patches), not coverage gaps (node patches). The queue's composition over time is the falsifiable version of "every path is answered": if node patches asymptote toward zero across adversarial sessions while alias/edge patches keep flowing, that is measurable evidence the objection space is near-complete — a metric, not an assertion.
