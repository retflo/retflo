# Security

## Official sources

retflo is published only here:

- Source: https://github.com/retflo/retflo
- Website: https://retflo.org

retflo is a text framework. It is made of Markdown files and a typed argument
graph. It contains no executables, no installers, and no compressed archives,
and it never will. There is nothing to download and run.

Any repository, download, or release that offers a retflo `.exe`, `.zip`,
installer, or other binary is not this project. Treat it as malicious and do
not run it.

At least one impersonating copy has existed on GitHub carrying a binary archive
that is flagged as malicious by antivirus vendors. It has been reported to
GitHub and to malware-analysis services. If you find another, please open an
issue here so the notice can be updated.

## Reporting a vulnerability

If you find a genuine security problem in this repository or on retflo.org, open
an issue, or contact the maintainer through the address listed at
https://retflo.org. There is no bug bounty; this is a solo, non-commercial
project, and reports are handled as time allows.
