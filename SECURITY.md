# Security

## Official sources

retflo is published only here:

- Source: https://github.com/retflo/retflo
- Website: https://retflo.org

The framework is Markdown: node files, documentation, and the typed connections
between them. The repository also carries plain JavaScript source for the MCP
server and its viewer, which you can read before you run it. No release contains
a compiled binary, an installer, or a compressed archive, and none ever will.

Any repository, download, or release that offers a retflo `.exe`, `.zip`,
installer, or other binary is not this project. Treat it as malicious. Do not
run it.

At least one impersonating copy has existed on GitHub carrying a binary archive
that antivirus vendors flag as malicious. It was reported to GitHub and to
malware-analysis services. If you find another, open an issue here so this
notice can be updated.

## Reporting a vulnerability

If you find a security problem in this repository or on retflo.org, write to
contact@retflo.org. For anything exploitable, please use email rather than a
public issue.
